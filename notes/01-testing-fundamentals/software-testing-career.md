# Software Testing as a Career Path

## Definition

To become a software tester, one must have great attention to details to be a competent tester. A tester doesn't only find bugs in the system but actually reads and understand project documentation of the project. This helps improve software quality by reporting defects, identifying gaps, and verifying fixes through re-testing.

---

## Key Points

- Needs both technical and non-technical skills
- Must keep on learning and improving sills
- QA is a continuous learning career with many specialization paths

---

I gained experience through manually testing the Expense Diary application, where I identified defects and documented them in a QA report.
